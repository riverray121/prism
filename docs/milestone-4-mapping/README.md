# Milestone 4 — Mapping

Implement Stage 2 of the project vision: map an analyzed song's features to lighting behavior, authored and previewed in the Mapping tab. Built against **one generic fixture** that carries every channel any future light will have (including an N-pixel dimension); rig, patching, Sim, and Hardware stay deferred.

The model was designed during M2 as a subfeature seed; those docs moved here and remain the reference:

| Doc                                    | Contents                                                                            |
| -------------------------------------- | ----------------------------------------------------------------------------------- |
| [`overview.md`](overview.md)           | Core model (feature → transform → channel → fixture), channels, macro layer         |
| [`catalog.md`](catalog.md)             | Every feature → channel mapping, derivations, complex data shapes, transforms       |
| [`formats.md`](formats.md)             | Mapping doc / rig / patch / cue schemas, versioning                                 |
| [`visualization.md`](visualization.md) | Ribbon lanes, live preview, usability principles (auto-map, progressive disclosure) |
